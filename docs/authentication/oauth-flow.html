Finsight OAuth Callback Flow

Use Ctrl + Plus / Ctrl + Minus to zoom
sequenceDiagram
    autonumber
    actor User as User
    participant Client as Finsight Client
    participant Backend as Finsight Backend
    participant Auth0 as Auth0
    participant DB as Database

    rect rgb(45, 45, 45)
    note over User,Auth0: Start OAuth
    User->>Client: Click Google/GitHub login
    Client->>Backend: GET /api/v1/auth/oauth/:provider
    Backend->>Backend: Create oauth_csrf token
    Backend-->>Client: Set-Cookie: oauth_csrf
    Backend-->>Client: 302 redirect to Auth0 authorize URL
    Client->>Auth0: Open Auth0 login page
    User->>Auth0: Login / consent
    Auth0-->>Backend: GET /api/v1/auth/callback?code=...&state=...
    end

    rect rgb(45, 45, 45)
    note over Backend,DB: Handle callback on Backend
    Backend->>Backend: Decode state and validate oauth_csrf
    Backend->>Auth0: POST /oauth/token with authorization code
    Auth0-->>Backend: Auth0 access_token
    Backend->>Auth0: GET /userinfo
    Auth0-->>Backend: User profile
    Backend->>DB: Find or create user
    DB-->>Backend: User
    Backend->>Backend: Create accessToken and refreshToken
    Backend-->>Client: Set-Cookie: refreshToken (httpOnly)
    Backend-->>Client: 302 /oauth-callback
    note right of Client: No accessToken in URL
    end

    rect rgb(45, 45, 45)
    note over Client,Backend: Sync logged-in session on Client
    Client->>Backend: POST /api/v1/auth/refresh-token
    note right of Client: Browser sends refreshToken cookie
    Backend->>Backend: Verify refreshToken
    Backend-->>Client: 200 { accessToken, expiresAt }
    Client->>Backend: GET /api/v1/users/me
    note right of Client: Authorization: Bearer accessToken
    Backend-->>Client: 200 current user
    Client->>Client: Store accessToken + user in Redux
    Client-->>User: Navigate to Dashboard
    end
